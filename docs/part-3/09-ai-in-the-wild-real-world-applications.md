### How familiar AI works

| Use case | Method | Description | Examples |
| --- | --- | --- | --- |
| Voice assistants | **NLP + deep learning** | Understand and process speech | Siri · Alexa |
| Recommendations | **Machine learning** | Analyze behavior to suggest items | YouTube · Netflix |
| Image recognition | **CNN** | Learn visual patterns and objects | Face unlock |
| Self-driving cars | **AI + deep learning** | Use sensors and computer vision | Tesla · Waymo |
| Chatbots | **Large language models** | Understand and generate text | ChatGPT |
